Privacidad del sitio web

Cómo se trata la información al visitar estas páginas o escribir a soporte.

Alcance y contacto

Esta política se refiere al sitio de Velox; no sustituye una política de privacidad de la aplicación. Para consultas escribe a spectralabsdev@gmail.com.

Alojamiento y visitas

Estas páginas se alojan en GitHub Pages. GitHub registra direcciones IP de los visitantes por seguridad. Consulta la política de privacidad de GitHub.

No incorporamos publicidad, herramientas de analítica ni cookies de seguimiento en estas páginas.

Consultas de soporte

Si nos escribes por correo, recibimos tu dirección y el contenido que envíes mediante Gmail para atender la solicitud. La correspondencia se conserva mientras sea necesaria para resolverla y atender obligaciones aplicables. Puedes solicitar su eliminación en el mismo correo.

No envíes contraseñas, tokens, registros de clientes ni código confidencial. Los reportes publicados en GitHub pueden ser vistos por cualquiera.

Enlaces externos

GitHub, las tiendas y los servicios a los que accedas desde esta web aplican sus propias políticas. La web no recibe los datos de tu organización Salesforce.
