# Velox for Mac

Public support and distribution repository for Velox, an independent Salesforce
development environment. Application source code is maintained privately.

## Downloads

The public macOS release is being prepared. Verified installers and release notes
will appear in [Releases](https://github.com/spectralabsdev/Velox/releases).
There is no public installer in this repository yet.

## Help and feedback

- Support website: https://spectralabsdev.github.io/Velox/support/
- [Report a bug or suggest a feature](https://github.com/spectralabsdev/Velox/issues/new/choose).
- Contact: spectralabsdev@gmail.com.

Issues are public. Do not include credentials, customer records, private code or
other confidential information. Send security reports by email.

## Website setup

Publish `docs/` from `main` through GitHub Pages. Enable Issues and use the forms
in `.github/ISSUE_TEMPLATE/`. The website privacy page describes the website;
the final desktop app privacy policy and distribution terms must be completed
before a binary release. This repository does not grant an open-source license
to the Velox application.
